О проекте
RaceStintTracker — инструмент для гоночных экипажей, позволяющий автоматически рассчитывать план стинтов на основе параметров гонки и отслеживать их выполнение в реальном времени.

Реализовано:
- CRUD для гонок, пилотов и стинтов
- Связи между сущностями (гонка → стинты → пилоты)
- Подключение к PostgreSQL через Entity Framework Core
- REST API на ASP.NET Core

В разработке:
- Автоматическая генерация плана стинтов согласно нижеописанных формул:
1. Кругов на стинт = Объём бака / Расход на круг
2. Конец стинта = Начало + Время круга × Кругов + Время пит-стопа
3. Учёт укороченного последнего стинта

- Редактирование плана в случае форс-мажоров (смена пилота, изменение кругов)
- Валидация данных через FluentValidation
- Авторизация (JWT)
- Фронтенд (React)
- Нормальный ReadMe
